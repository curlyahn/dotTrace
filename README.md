# DotTrace — 나만 보는 위치 타임라인

구글 타임라인처럼 내가 다닌 길을 지도에 보여 주지만, **기록은 이 휴대폰 안에만 저장**하는 안드로이드 앱입니다.
Dot(할 일 앱)과 같은 미니멀 다크 + 라임 포인트 스타일입니다.

- **움직이는 동안 1분마다 위치 저장** (설정에서 1·2·3·5·10·15·30분으로 변경), 목표 정확도 10m 내외
- **가만히 있으면 위치 업데이트를 끔**: OS 활동 인식(STILL) 또는 최근 5분간 25m 안에 머문 것으로 판단,
  다시 움직이면 활동 인식이나 '큰 움직임 감지' 하드웨어 센서가 깨워서 즉시 재개
- **빠르게 이동할 때** (시속 30km 이상): 15초마다 기록해 경로를 부드럽게, 시속 20km 아래로 2분 넘게 내려가면 원래 주기로
- **신호가 없을 때** (터널, 엘리베이터, 지하): 처음 3분은 10초마다 다시 시도, 계속 안 잡히면 30초 → 1분 → 5분 → 최대 15분 간격
- 오차 50m가 넘는 위치(기지국 위치 등)는 저장하지 않음
- **지도**: 날짜별 이동 경로와 지점, 하루 이동 거리, 점을 탭하면 시각·정확도·속도
- **지점 목록**: 'N 지점'을 누르면 시각·주소 목록, 누르면 지도에서 이동
- **내 장소**: 집·회사와 자주 가는 곳 최대 10개 등록 → 지도 이름표, 지점 목록·리포트에 이름으로 표시
- **월간·연간 리포트**: 수단별 이동 거리·시간, 가장 오래 머문 곳, 방문 지역. 매월 1일·매년 1월 1일에 알림
- **구글 타임라인 가져오기**: 휴대폰에서 내보낸 Timeline.json(또는 테이크아웃 Records.json)의 경로·머문 곳·이동 수단을 가져옴, 중복 건너뜀
- **하루 타임라인**: 머문 곳·이동을 시간순 목록으로, 머문 곳은 지도에 원 하나 + 이름·머문 시간
- **고치기·학습**: 머문 곳 이름·이동 수단을 고치면 같은 장소·경로에 다음에도 적용
- **집·회사 자동 제안**: 최근 3주 기록에서 밤·평일 낮에 머문 곳
- **정보·도움말**: 설정 → 정보 · 도움말
- **내보내기**: 하루 또는 전체 기록을 GPX 파일로 저장 (구글 어스, 등산 앱 등에서 열림)
- **재부팅 후 자동 재시작** ('항상 허용' 위치 권한이 있을 때)

## 개인정보

- 위치 기록은 기기의 로컬 DB(Room/SQLite)에만 저장하고, 어떤 서버로도 보내지 않습니다.
- 위치는 배터리를 아끼기 위해 OS의 **Fused Location**(GPS + Wi-Fi + 센서)에서 받습니다.
  이 과정에서 OS가 Wi-Fi·기지국 정보를 구글 위치 서비스에 조회할 수 있지만, 기록 자체는 휴대폰에만 남습니다.
- 지도는 **MapLibre + OpenFreeMap**(OpenStreetMap 데이터)을 씁니다. 회원가입·API 키·결제 계정이 없고, 지도 배경(타일)만 받아옵니다.
- 안드로이드 자동 백업(`allowBackup`)도 꺼서 구글 드라이브로 복사되지 않습니다. 백업은 GPX 내보내기로 직접 하세요.

## 이동 수단 추정 방법

모두 기기 안에서 계산합니다 (`trips/TripClassifier.kt`).

1. 반경 100m 안에 5분 이상 머문 곳을 '머무름'으로, 그 사이를 '이동'으로 나눕니다.
2. 이동은 걷는 속도 구간과 탈것 구간으로 다시 나눕니다 (예: 걷기 → 지하철 → 걷기). 2분 미만 조각은 앞 구간에 붙입니다.
3. 구간마다 아래 단서로 수단을 정합니다.

| 수단 | 단서 |
|---|---|
| 기차 | 평균 시속 110km 이상 또는 최고 170km 이상 |
| 지하철 | 위치가 안 잡힌 채 이동한 시간이 35% 이상 (평균 시속 15~90km), 또는 함께 이동하는 와이파이 + 신호 끊김 |
| 걷기 | 활동 인식 '걷기·뛰기' 60% 이상, 또는 평균 시속 6km 미만 |
| 자전거 | 활동 인식 '자전거' 50% 이상, 또는 차량 인식이 적고 평균 시속 8~28km |
| 버스 | 함께 이동하는 와이파이(같은 공유기가 1km 넘게 보임), 또는 1km당 정차 1.2회 이상 · 평균 시속 30km 이하 · 최고 70km 이하 |
| 자가용 | 그 밖의 차량 이동 |

- 와이파이는 OS가 이미 해 둔 검색 결과만 읽습니다 (새로 검색하지 않아 전력 소모 없음).
- 차량·자전거로 인식되면 15초 주기로 기록해 정차 패턴을 잡습니다.
- 추정이라 틀릴 수 있습니다. 특히 시내 자가용과 버스는 헷갈리기 쉽습니다.

## 1. 빌드 설정 (한 번만)

GitHub Actions가 APK를 만듭니다. 저장소 **Settings → Secrets and variables → Actions → Secrets → New repository secret** 에 하나만 넣으면 됩니다.

### `DEBUG_KEYSTORE_BASE64` — 서명 키
Dot 앱과 같은 서명 키(`dot-debug.keystore.base64.txt`)의 내용 전체를 넣습니다.
이 키의 SHA-1: `12:8B:4E:D3:59:9E:8B:87:BC:0C:ED:64:C2:11:A8:8F:A8:24:9D:4D`
빌드마다 같은 키로 서명해야 새 버전을 덮어쓰기 설치할 수 있습니다.

지도 API 키는 필요 없습니다.

## 2. 설치

1. `main` 에 푸시하면 **Actions** 탭에서 빌드가 돌아갑니다. 직접 돌리려면 Build APK → **Run workflow**
   (이때는 **Releases** 페이지에도 APK가 올라가 휴대폰에서 바로 받기 좋습니다)
2. 끝난 실행의 **Artifacts** 에서 `dottrace-release-apk` 를 받아 설치합니다.

## 배터리를 아끼는 방법

| 상황 | 동작 |
|---|---|
| 움직이는 중 | Fused Location 고정밀 요청, 주기마다 1개. OS가 최대 주기 2배까지 모아서 전달해 앱이 덜 깨어남 |
| 가만히 있음 | 위치 요청 해제 (GPS 꺼짐). 활동 인식·큰 움직임 센서만 대기 (전력 거의 0) |
| 빠른 이동 | 15초 주기, 단 최대 1분치를 모아서 전달 (앱은 1분에 한 번만 깨어남) |
| 신호 잃음 | 10초(3분) → 30초(~10분) → 1분(~30분) → 5분(~1시간) → 15분. 10시간 갇혀 있어도 시간당 4번만 시도 |
| 공통 | WakeLock 사용 안 함. 위치나 센서 이벤트가 올 때만 OS가 앱을 깨움 |

## 3. 처음 쓸 때

1. **기록 시작** → 위치 '정확한 위치', 알림, **신체 활동** 허용 (신체 활동은 정지 감지용)
2. **설정 → 안정적으로 기록하기**
   - 위치 **항상 허용**: 재부팅 후 자동으로 이어서 기록
   - **배터리 최적화 제외**: 화면이 꺼져도 1분 주기가 유지됨
   - 삼성 휴대폰: **설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱** 에 DotTrace 추가
